# DZ MAP Flutter app

## الخريطة الحالية
- يعرض التطبيق خريطة متجهية حقيقية عبر MapLibre Native.
- مصدر البلاطات: OpenFreeMap، والنمط المستخدم: Liberty.
- رابط النمط: https://tiles.openfreemap.org/styles/liberty
- بيانات الخريطة مبنية على OpenStreetMap.
- يسمح OpenFreeMap بالاستخدام التجاري، ويجب إبقاء إسناد OpenFreeMap / OpenMapTiles / OpenStreetMap ظاهراً.
- الخدمة العامة مجانية حالياً لكنها مقدمة كما هي ومن دون SLA أو ضمان استمرارية؛ راجع شروطها قبل إطلاق واسع أو الاعتماد التجاري النهائي.
- بيانات الطرق والتغطية تختلف حسب المنطقة وتحديثات OpenStreetMap؛ لا يعني عرض الخريطة أن كل طريق أو عنوان في الجزائر مكتمل أو مؤكد.

## الوظائف المنفذة في واجهة الخريطة
- عرض خريطة الجزائر الحقيقية مع تحريكها وتكبيرها وتصغيرها.
- زر تحديد موقع الهاتف مع طلب الإذن عند ضغط المستخدم فقط.
- إظهار إسناد مصدر الخريطة ورابط حقوق OpenStreetMap.
- لا يوجد تتبع للموقع في الخلفية.

## الملاحة والبحث
التوجيه turn-by-turn وحساب المسارات والبحث الجغرافي عن العناوين لم تُربط بعد. يلزم اختيار مزود توجيه/Geocoding أو استضافة محرك مبني على بيانات OSM، مع مراجعة شروط الاستخدام والحدود والتكلفة قبل تشغيلها للمستخدمين.

## إنشاء ملفات Android محلياً
من داخل مجلد app نفّذ:
```bash
flutter create . --platforms=android --org dz.dzmap --project-name dz_map
flutter pub get
flutter run
```

## بناء APK آلياً
يوجد GitHub Actions workflow في `.github/workflows/build-apk.yml`. كل تحديث على `main` داخل `app/` يشغّل بناء APK بنسخة release، ويرفع الناتج كـ artifact باسم `dz-map-release-apk` لمدة 14 يوماً. من تبويب Actions في GitHub افتح آخر تشغيل ثم نزّل artifact.

## أذونات Android
الـ workflow ينشئ مشروع Android ويضيف أذونات الإنترنت والموقع التقريبي والدقيق. يطلب التطبيق إذن الموقع فقط عندما يضغط المستخدم زر «موقعي»، ولا يطلب الموقع في الخلفية.

## Google Play
إعداد target SDK في workflow هو API 36. هذه النسخة للتجربة وليست تصريحاً بجاهزية النشر. قبل النشر يجب اختبار الخريطة والأذونات على أجهزة فعلية، ومراجعة شروط مزود الخريطة واستمراريته، وربط التوجيه والبحث عند اعتمادهما، وتجهيز سياسة الخصوصية وبيانات الأمان وتوقيع النشر.
