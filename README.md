# DZ MAP — خريطة الجزائر التجارية

منصة خرائط تجارية للجزائر تجمع بين الباحثين عن المحلات وأصحاب المحلات.

## النطاق المعتمد
- تغطية مستهدفة: كامل الجزائر.
- نوعا المستخدمين: المشتري والبائع.
- المنصة الأولى: Android عبر Flutter، مع قابلية التوسع إلى iOS والويب.
- لغة المنتج: العربية أولاً، مع تجهيز البنية للفرنسية.

## الحالة الحالية
هذا المستودع يحتوي على وثائق الأساس وهيكل أولي لواجهة Flutter. لم يتم بعد ربط مزود خرائط إنتاجي، أو قاعدة بيانات، أو مصادقة، أو محرك توجيه. لا تعتبر النسخة الحالية تطبيقاً جاهزاً للنشر.

## المجلدات
- app/: تطبيق Flutter.
- docs/MAP_DATA_AND_LICENSING.md: مصادر الخرائط والترخيص والامتثال.
- docs/ROADMAP.md: مراحل التنفيذ.

## مبدأ ترخيص الخرائط
لن نستخدم صور خرائط Google أو بيانات منسوخة منها. يمكن استخدام بيانات OpenStreetMap وفق ODbL مع الالتزام بالإسناد وشروط المشاركة بالمثل عند انطباقها. يجب اختيار مزود بلاطات/خرائط وتوجيه يسمح بالاستخدام التجاري ويغطي أحجام الاستخدام المتوقعة قبل الإطلاق العام.

## إخلاء مسؤولية
وجود بيانات مفتوحة لا يعني أن كل خادم بلاطات أو خدمة توجيه مجانية ومناسبة للاستخدام التجاري. راجع الوثائق القانونية والتقنية قبل تفعيل أي مصدر في الإنتاج.
