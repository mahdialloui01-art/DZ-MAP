# تقييم مزودي الخرائط — DZ MAP

آخر مراجعة للمصادر: 8 نوفمبر 2026. الأسعار والخطط قابلة للتغيير ويجب إعادة التحقق منها قبل الاشتراك.

## القرار التقني
نستخدم MapLibre كمحرك عرض داخل Flutter، ونفصل بين:
- خدمة بلاطات/ستايل الخريطة.
- خدمة البحث الجغرافي (Geocoding).
- خدمة التوجيه وحساب المسارات.
قد يقدم المزود أكثر من خدمة، لكن يجب التحقق من ترخيص كل خدمة وخطتها على حدة.

## مقارنة أولية

### Stadia Maps
- يدعم بلاطات Vector Basemaps مناسبة لـ MapLibre.
- صفحة الأسعار تعرض Starter بسعر 20 دولاراً شهرياً، وتذكر السماح بالاستخدام التجاري، مع خدمات geocoding الأساسية/القياسية.
- الخطة المجانية لا تسمح بالاستخدام التجاري؛ استخدام تطبيق يحقق دخلاً بالإعلانات أو غيرها يعد تجارياً وفق FAQ.
- التوجيه القياسي ظاهر ضمن خطة Standard في جدول الأسعار، لذلك لا نفترض أنه متاح في Starter.
- الإسناد يختلف حسب الستايل؛ المثال المعتاد: © Stadia Maps © OpenMapTiles © OpenStreetMap contributors. يجب أخذ النص الدقيق من دليل الستايل الذي سنختاره.
- يلزم اشتراك مدفوع قبل تشغيل التطبيق تجارياً.

المصادر:
- https://stadiamaps.com/pricing/
- https://stadiamaps.com/faqs
- https://stadiamaps.com/terms-of-service/
- https://stadiamaps.com/attribution/

### MapTiler
- يوفر بلاطات Vector وRaster ويمكن استخدامه مع MapLibre.
- الخطة المجانية موصوفة للاختبار أو الاستخدام الشخصي/غير التجاري؛ لا نستخدمها لإطلاق تجاري.
- صفحة الشروط تشترط إظهار © MapTiler ورابط حقوقه، وإظهار © OpenStreetMap عند اعتماد بيانات OSM، مع إسناد إضافي حسب الستايل.
- صفحة الأسعار تعرض Flex بسعر ابتدائي 30 دولاراً شهرياً؛ يجب التأكد من حدود الاستخدام وشروط الخطة التجارية قبل اعتمادها.
- يجب التأكد من تغطية الجزائر وتفاصيل geocoding/routing بشكل منفصل.

المصادر:
- https://www.maptiler.com/cloud/pricing/
- https://www.maptiler.com/terms/

### Jawg Maps
- صفحة الأسعار تعرض خطة Professional للاستخدام التجاري بسعر 250 يورو شهرياً، وخطة Enterprise بسعر 500 يورو شهرياً وفق الجدول المعروض.
- الخطة المجانية مخصصة للاستخدام غير التجاري وفق تعريف الصفحة.
- السعر يبدو مرتفعاً كبداية لمشروع DZ MAP؛ نحتفظ به كخيار للمقارنة ولا نعتمده الآن.

المصدر:
- https://www.jawg.io/en/pricing/

## توصية المرحلة الحالية
نضع Stadia Maps كمرشح أول للاختبار التقني فقط، وليس كمزود معتمد نهائياً. السبب: وجود خطة Starter تجارية معلنة وبلاطات Vector مناسبة لـ MapLibre. قبل الشراء يجب:
1. التأكد كتابياً أو من لوحة الحساب أن الاستخدام في تطبيق Android تجاري متاح في الجزائر.
2. معرفة الحصة الشهرية وحدود الطلبات والتكلفة عند تجاوزها.
3. فحص ظهور الطرق والتسميات في الجزائر العاصمة وقسنطينة ووهران والطرق بين الولايات.
4. التحقق من geocoding وrouting المتاحين في الخطة، وعدم افتراض أن خطة الخرائط تشمل التوجيه.
5. حفظ نص الإسناد والرابط المطلوبين للستايل المختار.
6. اختبار الأداء على هاتف Android واتصال ضعيف.

## إعداد التطبيق
لا تضع مفاتيح سرية في GitHub أو داخل المستودع. مفاتيح مزود الخرائط التي يلزم وجودها في تطبيق الهاتف ليست سرية بالكامل بعد توزيع التطبيق؛ يجب تقييدها من لوحة المزود إن كان يدعم ذلك، ووضع حدود للاستهلاك والتنبيهات.

عند تشغيل Flutter مرّر القيم من إعدادات البناء:
- DZ_MAP_STYLE_URL: رابط JSON لستايل MapLibre.
- DZ_MAP_ATTRIBUTION: نص الإسناد الدقيق الذي يفرضه المزود والستايل.
- DZ_MAP_ATTRIBUTION_URL: رابط صفحة حقوق المزود/المصادر.

مثال تشغيل محلي (استبدل القيم بقيم حسابك المرخص، ولا تضع مفاتيح حقيقية في commit):
```bash
flutter run \
  --dart-define=DZ_MAP_STYLE_URL=https://YOUR_PROVIDER/style.json \
  --dart-define="DZ_MAP_ATTRIBUTION=© Provider © OpenStreetMap contributors" \
  --dart-define=DZ_MAP_ATTRIBUTION_URL=https://YOUR_PROVIDER/attribution
```

لا نضع رابطاً تجريبياً في التطبيق على أنه مصدر إنتاجي. ولا نعتبر الخريطة جاهزة حتى ينجح اختبار التغطية والترخيص.
