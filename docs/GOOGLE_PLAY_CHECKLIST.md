# قائمة مراجعة Google Play — 2026

هذه قائمة تحضير وليست ضماناً لقبول التطبيق. يجب إعادة فحص السياسات يوم الإرسال لأن المتطلبات تتغير.

## مستوى Android API
بحسب صفحة Google Play الرسمية التي تمت مراجعتها بتاريخ 8 نوفمبر 2026، يجب أن تستهدف التطبيقات الجديدة والتحديثات Android 16 (API level 36) أو أعلى ابتداءً من 31 أغسطس 2026. يجب التحقق من targetSdkVersion في مشروع Android النهائي قبل بناء AAB.

المصدر الرسمي:
https://support.google.com/googleplay/android-developer/answer/11926878

## عناصر لازمة قبل الإرسال
- [ ] إنشاء مشروع Android فعلي عبر Flutter وتثبيت إعدادات Gradle المتوافقة.
- [ ] ضبط targetSdkVersion إلى API 36 أو أعلى عند الحاجة.
- [ ] اختبار التطبيق على أجهزة Android فعلية وإصدارات متعددة.
- [ ] مراجعة أذونات الموقع؛ طلب الإذن وقت الحاجة فقط وشرح سبب استخدامه.
- [ ] إضافة سياسة خصوصية عامة ورابط صالح.
- [ ] تعبئة Data safety بما يطابق سلوك التطبيق الحقيقي ومكتباته.
- [ ] إعداد صفحة المتجر، لقطات الشاشة، الأيقونة، والوصف.
- [ ] اختبار تسجيل البائع والمشتري، الإبلاغ عن المحتوى، وحذف الحساب عند انطباق المتطلبات.
- [ ] تدقيق إسناد الخرائط وشروط مزود البلاطات والتوجيه.
- [ ] فحص AAB النهائي واختبار مسار التثبيت والتحديث.

## لا نعلن الجاهزية قبل
1. وجود مزود خرائط وتوجيه إنتاجي مرخص ومفعّل.
2. عمل الخريطة والبحث والملاحة فعلياً.
3. اختبار بيانات الطرق في مناطق جزائرية متعددة.
4. اكتمال الخصوصية والأمان والاختبارات.
5. مراجعة Play Console النهائية.
